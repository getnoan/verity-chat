# Verity Chat

A grounded chat widget for your website — one script tag, and the answers come from your
[NOAN](https://www.getnoan.com) fact layer, never from a model's imagination. The service
serves its own embed (/widget.js), streams replies, shows visitors which facts it read,
files support cases as tasks, and writes a wrap-up memo to the contact when they leave.

**Install:** hand INSTALL.md to your coding agent. Step 0 runs the shell locally with no
keys in about a minute.

Spend is capped by a daily budget you set; conversations ride signed visitor tokens; the
API answers only your site's origins.

Exported one-way from the private fleet repo; see scripts/check-provenance.mjs.
